# T-04 — Player/fly controller, debug overlay, settings
ID / milestone / wave / risk: T-04 / M0 / wave 2 / low

## Goal and why
Let the owner move through the world and see fps and memory, so the M0 performance test can be run on their PC.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (the "Invariants" section, especially invariant 4 on input actions).

## Interfaces / invariants
- `entities/player.gd` (a CharacterBody3D with a child Camera3D at eye height 1.62 m, in scene `entities/player.tscn`):
  - mouse-look, with the mouse captured while playing and released on `menu`;
  - walk 4.3 m/s, sprint 5.6 m/s, jump, gravity;
  - fly mode on `toggle_fly` (no gravity, 10 m/s, `jump` to go up, `dodge` to go down);
  - the player reads only InputMap actions.
- `ui/debug_overlay.tscn`/`.gd` (CanvasLayer), toggled with `toggle_debug` and visible by default in M0. It shows:
  - fps;
  - frame time in ms;
  - static memory in MB (`Performance.MEMORY_STATIC`);
  - draw calls;
  - the renderer name (`RenderingServer.get_current_rendering_method()`);
  - the GPU name (`RenderingServer.get_video_adapter_name()`);
  - position.

  It refreshes every 0.25 s.
- A `Settings` autoload (game/settings.gd) stored at `user://settings.json`: `view_radius_chunks:int=4`, `fullscreen:bool=false`, `mouse_sensitivity:float=0.002`. It has `load_settings()` and `save_settings()`, and missing keys fall back to defaults.
- Add the environment to `main.tscn`: a WorldEnvironment with depth fog (density 0.012, colour #9fb4c7), a sky colour, ambient light, and a DirectionalLight3D with shadows off.
