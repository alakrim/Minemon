# T-01 — Project scaffold, tooling, check command
ID / milestone / wave / risk: T-01 / M0 / wave 1 / high (it defines tooling everyone depends on)

## Goal and why
Create the Godot 4.7.2 project skeleton and a working `scripts/check.sh`, so that every later task has one command proving the repo is healthy.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (sections "Architecture" and "Invariants").

## Interfaces / invariants
- The folder layout must match the PLAN.md "Architecture" tree exactly. Create the empty folders with a `.gitkeep`.
- `project.godot`:
  - name "Minemon";
  - renderer `gl_compatibility` for both desktop and mobile;
  - window 1280×720, resizable;
  - main scene `res://main.tscn` (a minimal Node3D with a Camera3D and a Label saying "Minemon M0");
  - the InputMap actions listed below, with keyboard/mouse defaults.
- InputMap actions: `move_forward`(W) `move_back`(S) `move_left`(A) `move_right`(D) `jump`(Space) `sprint`(Shift) `dodge`(Ctrl) `attack`(LMB) `throw_ball`(RMB) `move_1`..`move_4`(1–4) `send_out`(Q) `interact`(E) `menu`(Esc) `toggle_debug`(F3) `toggle_fly`(F).

## Steps
1. `scripts/setup.sh` (bash, idempotent):
   - Download Godot 4.7.2 Linux x86_64 from `https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_linux.x86_64.zip` into `.tools/` and symlink it as `.tools/godot`.
   - `pip install --break-system-packages "gdtoolkit==4.*"`.
   - Skip anything already present.
2. Vendor GUT (latest release compatible with Godot 4.7) into `addons/gut/`, taken from its GitHub repo `bitwes/Gut` (MIT licence). Add it to `ASSETS_LICENSES.md` under a "Code dependencies" heading. Enable the plugin in project.godot.
3. `gdlintrc`: gdtoolkit defaults, with max-line-length 110, and `addons/` excluded.
4. `scripts/check.sh` (bash, `set -euo pipefail`). Run these steps in order, printing a header for each:
   - (a) `gdformat --check` over all .gd files outside `addons/`;
   - (b) `gdlint` over the same files;
   - (c) `$GODOT --headless --import` (first import), failing on any `ERROR` line in its output;
   - (d) the GUT command line headless over `res://tests` with exit-on-finish. It exits non-zero on any failure, and also when zero tests ran.

   Print `CHECK PASSED` at the end. `GODOT` defaults to `.tools/godot`.
5. Add `tests/smoke/test_boot.gd`, which instances `main.tscn` and asserts it has a Camera3D.
6. Add `.gitignore` entries for `.tools/`, `.godot/`, `builds/`, `packs/*` (keeping `!packs/README.md`) and `*.import`. Add a `packs/README.md` placeholder that says "Owner asset pack folder. Format defined in a later task."
7. Update the "Key commands" section of `CLAUDE.md` to list `scripts/setup.sh` and `scripts/check.sh`.

## Out of scope / files not to touch / permitted dependencies
- Do not write any game logic.
- Touch only: project.godot, main.tscn, the folder skeleton, addons/gut/, scripts/setup.sh, scripts/check.sh, gdlintrc, .gitignore, packs/README.md, ASSETS_LICENSES.md, tests/smoke/test_boot.gd, and the CLAUDE.md "Key commands" section.
- Permitted dependencies: GUT and gdtoolkit only.

## Acceptance criteria and verification
1. On a clean clone, `bash scripts/setup.sh && bash scripts/check.sh` exits 0 and prints `CHECK PASSED`. A second run of setup.sh downloads nothing.
2. check.sh exits non-zero if a test fails. Verify with a temporary failing test, then remove it.
3. check.sh exits non-zero on a lint or format violation. Verify, then revert.
4. All 17 InputMap actions exist. Verify with `grep -c` on project.godot or a test.
5. `git status` shows no `.tools/` or `.godot/` files.
