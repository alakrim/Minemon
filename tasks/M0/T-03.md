# T-03 — Voxel world: blocks, chunks, terrain, mesher, streamer
ID / milestone / wave / risk: T-03 / M0 / wave 2 / medium

## Goal and why
Build a blocky world that streams in around a position, fast enough for an AMD Vega 8 iGPU. This is the core performance risk of the project (D-015).

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (the "Architecture", "Interfaces" (Chunk, ChunkMesher, TerrainGenerator) and "Invariants" sections).

## Interfaces / invariants
- `Chunk`, `ChunkMesher.build` and `TerrainGenerator` exactly as specified in PLAN.md. In M0, `RegionData` may be a stub class (`world/region_data.gd`) with no fields.
- `BlockRegistry` (world/block_registry.gd): loads data/blocks.json (`[{id:int, name, color:"#rrggbb", solid:bool, transparent:bool}]`). Ids: 0 air, 1 grass, 2 dirt, 3 stone, 4 sand, 5 water, 6 log, 7 leaves, 8 snow.
- Rendering in M0 uses vertex colours, with no textures yet. A slight per-face shade (top 1.0, sides 0.8, bottom 0.6) gives a Minecraft look.
- `WorldStreamer` (world/world_streamer.gd, extends Node3D):
  - `seed:int` and `view_radius_chunks:int` (default 4);
  - `set_focus(pos:Vector3)`;
  - loads chunks within the radius (all Y chunk layers 0..7, so world height is 128) and unloads those beyond radius+1;
  - generation and meshing run on `WorkerThreadPool`; only the main thread adds MeshInstance3D nodes;
  - each chunk gets a trimesh collision shape built from the same mesh, so the player can walk on it;
  - `loaded_chunk_count() -> int`.
- Terrain: seeded `FastNoiseLite` heightmap (sea level 32, heights 20–90). Biomes come from a second noise: plains/forest/mountain/beach. Trees use the seeded `Rng` (world/rng from core/rng.gd).
- Same seed gives identical blocks (invariant 2).

## Steps
1. Write blocks.json, block_registry.gd, chunk.gd, terrain_generator.gd, chunk_mesher.gd, world_streamer.gd and region_data.gd.
2. Write unit tests in tests/unit/ covering:
   - chunk get/set and its bounds;
   - one solid cube mesh produces 6 faces and 2 adjacent cubes produce 10 faces;
   - generator determinism (same seed gives the same chunk, a different seed a different chunk);
   - blocks.json loading;
   - the streamer loading the expected chunk count for radius 1 in a headless SceneTree.

## Out of scope / files not to touch / permitted dependencies
- No player, camera, UI or textures. Touch only world/, data/blocks.json and tests/unit/test_world_*.gd. No new dependencies; T-02 may be in progress in parallel.
- If core/rng.gd does not exist yet, create a minimal `world/world_rng.gd` wrapper around RandomNumberGenerator instead, and note this in your report.

## Acceptance criteria and verification
1. `bash scripts/check.sh` exits 0.
2. The mesher test confirms hidden-face culling (6 and 10 faces).
3. The determinism test passes.
4. A benchmark test (`tests/unit/test_world_bench.gd`) times generating and meshing 64 chunks headless and prints the ms per chunk. Record the number in your report; there is no pass/fail threshold.
5. `ChunkMesher` and `TerrainGenerator` contain no `get_tree`, `add_child` or Node references (they must be thread-safe).
