# T-05 — Integration, benchmark mode, Windows export (.zip)
ID / milestone / wave / risk: T-05 / M0 / wave 3 / medium
Depends on: T-01, T-02, T-03, T-04 (all DONE).

## Goal and why
Deliver the M0 demo: a Windows .zip the owner unzips and runs. It contains a generated world they can walk through and a 60-second benchmark that writes its results to a file next to the exe. This answers the performance risk (D-015).

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (the "Milestones" row for M0), and the reports tasks/M0/T-03.report.md and T-04.report.md.

## Interfaces / invariants
- `main.tscn` wiring:
  - the WorldStreamer (seed 1337, radius from Settings);
  - the player spawned on the surface at (0, height+2, 0);
  - `WorldStreamer.set_focus(player.position)` called each frame;
  - the debug overlay.

  Do not start the player until the spawn chunk has collision; show a "Generating world…" label until then.
- Benchmark mode starts when the `--benchmark` user argument is present (`OS.get_cmdline_user_args()`). The camera flies a fixed square path (side 160 m, 20 m above terrain, 60 s), which forces chunk streaming. At the end the game writes `benchmark_<renderer>_<yyyyMMdd_HHmm>.txt` next to the executable (`OS.get_executable_path().get_base_dir()`, falling back to `user://`) and quits. The file contains: avg fps, 1% low fps, min fps, max static memory MB, peak loaded chunks, renderer, GPU name, view radius.
- `export_presets.cfg` holds a "Windows Desktop" preset for x86_64 with PCK embedded and `packs/` excluded.
- `scripts/export_windows.sh`:
  - downloads the 4.7.2 export templates (`https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz`) once, into `.tools/templates/`, installing them where Godot expects them (`~/.local/share/godot/export_templates/4.7.2.stable/`);
  - exports `builds/Minemon-M0/Minemon.exe`;
  - writes 4 .bat files next to the exe:
    - `Play (low-end).bat`: runs the exe with `--rendering-method gl_compatibility`;
    - `Play (Vulkan).bat`: runs it with `--rendering-method mobile`;
    - `Benchmark (low-end).bat`: the low-end command plus ` -- --benchmark`;
    - `Benchmark (Vulkan).bat`: the Vulkan command plus ` -- --benchmark`;
  - writes a `LEIA-ME README.txt` (in English with Portuguese headings) with click-level instructions: unzip, double-click Benchmark (low-end), wait 60 s, then send the .txt file; and the same for Vulkan;
  - zips everything into `builds/Minemon-M0-windows.zip`.
- Add a smoke test that runs the main scene headless for 120 frames with radius 1 and asserts at least 1 chunk loaded and no errors.

## Out of scope / files not to touch / permitted dependencies
- No gameplay. Touch only main.tscn, main.gd (new), game/benchmark.gd (new), export_presets.cfg, scripts/export_windows.sh, tests/smoke/test_main.gd, and .gitignore (if needed). No new dependencies beyond the official export templates.

## Acceptance criteria and verification
1. `bash scripts/check.sh` exits 0.
2. `bash scripts/export_windows.sh` exits 0 and produces `builds/Minemon-M0-windows.zip`, containing Minemon.exe, the 4 .bat files and the README. `unzip -l` lists them.
3. A headless benchmark run on Linux works: `$GODOT --headless --path . -- --benchmark` with a temporary 5 s duration override (`--bench-seconds=5`) writes a result file with all 8 fields.
4. The zip size is reported. Target: under 150 MB.
