# T-02 — Core interface stubs, data contracts, contract tests
ID / milestone / wave / risk: T-02 / M0 / wave 2 / high (interfaces)

## Goal and why
Create the typed interfaces from PLAN.md, along with sample data and contract tests, so that later milestones build against stable signatures.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (the "Interfaces", "Data contracts" and "Invariants" sections). Everything must follow them exactly.

## Interfaces / invariants
- Implement the signatures exactly as written in PLAN.md for: `Rng`, `SpeciesData`, `MoveData`, `Stats`, `Damage` (plus `CombatantView` and `DamageResult` as simple typed RefCounted records), `Catch`, `Exp`, `Lives`, and the `Data` autoload (`game/data_registry.gd`).
- `Rng`: a real implementation wrapping `RandomNumberGenerator` with the given seed. `fork(tag)` seeds a new Rng from `hash(str(seed) + tag)`.
- `Lives`: a real implementation. It starts at 3; deaths 1 to 3 return "respawn" and decrement `lives_left`; the 4th death returns "permadeath".
- `Data.load_all()`: a real implementation. It parses `data/species.json`, `data/moves.json` and `data/types.json`, and validates every field against the data contracts: types, enums and ranges, plus every learnset move id existing in moves.json and every evolution target existing (or being a not-yet-loaded id, which is allowed only in M0). It returns a list of human-readable errors.
- `Stats`, `Damage`, `Catch`, `Exp`: implement them faithfully, following these formulas.
  - Stats, Gen-2 style:
    - HP = floor((2·base + iv)·L/100) + L + 10;
    - other stats = floor((2·base + iv)·L/100) + 5;
    - bond adds +0 to +10% (floor(bond/25)%).
  - Damage = floor(floor(floor(2·L/5+2)·power·A/D)/50)+2, then × STAB 1.5 × type multiplier × crit 2.0 (chance 1/16) × random 0.85..1.0 (from `Rng`). Status moves deal 0.
  - Catch: a = (3·max − 2·cur)·rate·ball/(3·max) × status, where ball = {poke:1, great:1.5, ultra:2, master:255} and status = {none:1, sleep/freeze:2, paralysis/burn/poison:1.5}. The chance is min(1, a/255).
  - Exp: gain = floor(base_exp·L_defeated/7 × (1 + bond/510)). `level_for` uses the standard Gen 1–2 growth-rate curves.

## Steps
1. Write the core/ files and game/data_registry.gd (an autoload named `Data`, registered in project.godot).
2. Write data/types.json (the full Gen 2 type chart, 17 types) and data/species.json with 4 sample species: Rattata (19), Pidgey (16), Cyndaquil (155) and Gastly (92). Add data/moves.json with every move those learnsets need up to level 15. Values must be correct per Gen 2 (PokeAPI is the reference). The design fields (temperament, size_class, etc.) are your sensible choice.
3. Write the contract tests in tests/contract/, one file per interface, checking signatures and return types. Write unit tests in tests/unit/, covering at least:
   - Rng determinism;
   - Lives respawn/permadeath;
   - the damage formula against one hand-computed case;
   - catch-chance bounds and ball ordering;
   - stats at L5 and L50 for one species;
   - exp levels;
   - `load_all()` returning [] on the shipped data and returning errors on a broken fixture in tests/fixtures/.

## Out of scope / files not to touch / permitted dependencies
- No world, scenes or UI. Touch only core/, game/data_registry.gd, data/, tests/contract/, tests/unit/, tests/fixtures/, and the autoload line in project.godot. No new dependencies.
