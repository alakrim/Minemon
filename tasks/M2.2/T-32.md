## Interfaces / invariants
Read knobs with `minemon.tuning.get(key)` at the moment of use. Use the helpers in `minemon.tuning.logic` (`apply_catch`, `apply_level`, `apply_chance`). Guard each read so the code still works if `minemon.tuning` were nil (`local T = minemon.tuning` then `if T then ... end`). With every knob at its default, behaviour must be byte-for-byte the same as now (same RNG draws in the same order).
1. **Capture** (minemon_capture/init.lua): in BOTH `odds_for` and `begin`, after `p = L.effective_p(...)`, apply `p = logic.apply_catch(p, get("catch_mode"), get("catch_mult"))`. The odds HUD then shows the tuned odds, and the roll uses them.
2. **Spawning on/off and crowd** (minemon_creatures/spawning.lua `gate`): return false when `spawn_enabled` is false. The local cap becomes `math.floor(LOCAL_CAP * spawn_cap_mult + 0.5)` (0 means no natural spawns).
3. **Level offset** (spawning.lua `M.level_at`): return `logic.apply_level(base, get("level_offset"))`. The level gate and on_spawn both go through level_at, so they stay consistent. `API.spawn` with an explicit level must NOT be offset (the admin chooses an exact level).
4. **Dread chance** (minemon_creatures): the Dread roll must use `chance × dread_mult`, clamped to 1. Do it without breaking `dread_logic.roll`'s "one float drawn when the chance is not zero" rule. Prefer an optional 5th parameter `mult` on `dread_logic.roll` (default 1); pass it from `make_on_spawn`. Keep dread_logic.lua pure (it must not read minemon.tuning).
5. **Shiny** (defs.lua `roll_shiny(rng)`): add an optional `mult` (default 1). Odds become `mult / SHINY_ODDS` clamped to 1. At mult 1 it must still be `rng:int(1, SHINY_ODDS) == 1` (same draw). For other mults use one `rng:float() < p` draw. Pass the knob from `make_on_spawn` and `API.spawn`.
6. **Exp** (minemon_growth/init.lua, `creature_defeated` handler): gain = `math.floor(exp_gain(...) * exp_mult + 0.5)`; skip grant_exp when the result is 0.
